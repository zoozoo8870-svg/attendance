☁️ เชื่อม Google Sheet (ให้ทุกคนเช็คชื่อจากมือถือตัวเองได้)

ถ้ายังไม่เชื่อม ข้อมูลจะเก็บไว้ในมือถือเครื่องนี้เครื่องเดียว เหมาะกับให้เจ้าหน้าที่ถือเครื่องเดียวเช็คชื่อให้ทุกคน
วิธีตั้งค่า (ทำครั้งเดียว ~5 นาที)
  1. เปิด Google Sheet ใหม่ → เมนู ส่วนขยาย → Apps Script
  2. ลบโค้ดเดิมทิ้ง แล้ววางโค้ดด้านล่าง (กดปุ่มคัดลอกได้เลย) → กดบันทึก
  3. กด ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เลือกประเภท เว็บแอป
  4. ตั้ง “ดำเนินการในฐานะ” = ฉัน และ “ผู้มีสิทธิ์เข้าถึง” = ทุกคน → กดทำให้ใช้งานได้ และอนุญาตสิทธิ์
  5. คัดลอก URL ที่ลงท้ายด้วย /exec มาวางในช่องด้านบน
  6. ถ้าจะให้มือถือทุกเครื่องใช้ได้ทันที ให้นำ URL ไปใส่ในไฟล์ index.html ตรง SCRIPT_URL ด้านบนสุดของสคริปต์ แล้วอัปโหลดไฟล์ใหม่
